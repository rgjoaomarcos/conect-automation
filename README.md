# 🏥 CONECT Productivity Automation

Automação simples para extrair produtividade dos plantonistas da UPA São Leopoldo Mandic.

## ⚙️ Configuração

1. Copie `.env.example` para `.env` e preencha com suas credenciais
2. Deploy no Railway com os arquivos inclusos
3. Railway roda automaticamente às 7h todo dia

## 📊 Saída

Gera CSV diário: `YYYY-MM-DD_produtividade.csv`

Colunas: médico, paciente, data_hora

## 🚀 Deploy

Railway faz o deploy automático a partir do GitHub.
